Machine learning project for predicting customer churn using XGBoost, CatBoost, and LightGBM with data preprocessing, visualization, and model evaluation.
**Customer Churn Prediction using Machine Learning**
This project predicts whether a customer is likely to leave a company’s service using Machine Learning algorithms. It includes data preprocessing, exploratory data analysis, feature engineering, model training, and evaluation. Models like XGBoost, CatBoost, and LightGBM are used to improve prediction accuracy. The project helps businesses identify high-risk customers and improve customer retention strategies.

**Technologies Used**
